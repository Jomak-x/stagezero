# Additional full-workflow demos

These clips extend the curated Stage One V2 package. Each new recording follows actual studio operations, with source-speed hard cuts removing idle navigation or backend waits. No subtitles, descriptions, music, narration, or interpolated frames are added to the video.

The in-app recorder composites actual live WebGL and timeline canvases with event-driven editor snapshots. Small transient menu/input states may be missed between overlay snapshots. Motion quality is checked on active playback windows rather than inferred from the file's frame rate.

The new character creation attempt again waited on shared GPU memory. It is not presented as a successful completed 3D-character workflow. Two-person Handshake uses the studio's explicitly labeled reviewed interaction with generated approaches; the footage does not claim the handshake itself was freshly generated. Multi-person research outputs are reviewed visually for usable contact and foot placement.

Raw captures, cut manifests, editable projects, and QA remain in the local working archive. Published media packages include only selected successful workflows and review metadata.

## New workflow coverage

1. Create two camera views, add timeline cuts, and preview the sequence in a living room.
2. Generate a harbor greeting, append a bow, rename the take, save a shorter copy, and compare playback.
3. Build a residential scene, stage two actors and a meeting point, generate the approach/handshake, revise the meeting point, and replay closer.
4. Generate three simultaneous actions in a neon lab, replace the direction with bow/stretch/squat, and review the completed new performance.
5. Generate a custom brass telescope, move and rotate it beside the character, and replay the existing performance.

The telescope is a generated decorative prop; the actor does not interact with it. The camera clip demonstrates cuts and preview, not a separately verified FOV value. A foreground sphere briefly occludes part of the robot during the later camera playback.

The three-person revision's first recording retained a stale editor snapshot while generation finished. The completed saved performance was reopened and recorded again; the final edit joins the original direction workflow to that verified result. Long waits, a rejected prompt-expansion retry, and an unsuccessful rotated meeting-point attempt are omitted. These are edited demonstrations, not uninterrupted recordings or generation latency benchmarks.

The complete 16-demo reel joins the original 11 selected V2 demos with these five new workflows. The new-workflow reel contains only these five. Both retain source-speed playback; 30 fps delivery does not imply every source frame was captured at 30 fps.

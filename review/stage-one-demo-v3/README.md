# Stage One — additional workflows

Five silent, separately editable workflow videos accompany the original 11 selected demos.

- `Stage-One-All-Demos.mp4`: the five new workflows.
- `Stage-One-Complete-16-Demos.mp4`: all 16 selected demos, with the original 11 followed by the five new workflows.
- `clips/`: individual new videos.
- `FILE-LIST.csv`: new clips with timestamps in the new-workflow reel.
- `COMPLETE-FILE-LIST.csv`: all 16 clips with timestamps in the complete reel. Original clips are in the adjacent `stage-one-demo-v2` package.
- `index.html`: local preview gallery for the five new workflows.
- `thumbnails/`: still previews.
- `PRODUCTION-NOTES.md`: capture, editing and capability details.

The complete reel runs 8:28. Videos contain no added audio, captions or title cards. Playback is source speed; hard cuts remove waits and idle navigation. See production notes for limits and the distinction between live capture and delivery frame rates.

# Input-driven simultaneous cast motion

Production integration of the previously reviewed optional experiment. In **Motion → AI cast · 1–3 people**, enter e.g.:

- Three people celebrate together in place for six seconds, raising their arms and cheering independently without touching.
- Three people wave hello at the same time for six seconds, standing apart.
- Two people shake hands for four seconds while a third waves during the handshake.

The existing planner explicitly emits `concurrent_solos`; it is not a keyword-triggered canned clip. Each independent actor is generated by Core with private history. Existing plans without that field retain their legacy builder path. One concurrent beat only, 2–10 seconds for independent solos and 2–7 seconds for pair-plus-third. Pair-plus-third reserves actor_1/actor_2 as the pair and overlays actor_3 over the resolved pair-action frames, with bounded authored entry/exit bridges. Simultaneous choreography/contact among three bodies is unsupported. Ten actors remain an offline research experiment, not a production UI capability.

The paired payload is byte-identical before/after overlay. Post-generation geometry/bridge rejection preserves original motion and prominently reports requested concurrency was not achieved. Cancellation and worker failures propagate; all candidates and raw sources are retained. No previous UI, source pair generation, source geometry gates, browser protocol, actor/archive limits, or live service was replaced.

## Reproduce

Run from the repository root with normal dependencies, pinned ARDY submodule and built Studio client:

```sh
PYTHONPATH=.:vendor/ardy python -m unittest discover
# Requires reservation of the existing workers; no provisioning:
PYTHONPATH=.:vendor/ardy python experiments/trial_group_prompt.py --token /path/to/private-token --provider-config /path/to/private-provider.json --gateway-env /path/to/private-gateway.env --model-lane-reserved
# Replay saved performance without generating:
python director_viewer.py --reference-only --native-project review/group-prompt-integration/celebrate-city-91/attempt-001/scene.cast.stagezero.npz --port 24978
# Rebuild final short reel from complete exported captures:
python review/group-prompt-integration/build-reel.py
```

`capture.json` can be used with `experiments/capture_cast_review.py --manifest ... --output-root /new/output --port 24979 --client-build /existing/build`. Trials retain frozen first-attempt input/provenance and actual planner outputs; new generation attempts get new numbered folders. Prior research comparisons and rejected mid-scene overlay remain in `review/group-motion-probe`.

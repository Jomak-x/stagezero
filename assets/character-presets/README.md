# Ready-to-use character presets

Explorer, space mechanic and park ranger are existing Neon + TRELLIS generated
assets from this project, bundled so the gallery works without a GPU connection.
PNG thumbnails are the original design references. GLBs are their completed
textured meshes, fitted to body motion by CharacterControls. These are
approximate body rigs; fingers and faces are not independently animated.

The models are reused as presets, never reported as a newly generated result.

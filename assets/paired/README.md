# Native paired display rig

`Xbot.glb` is the authored, skinned Xbot asset from the official Three.js examples:
https://raw.githubusercontent.com/mrdoob/three.js/dev/examples/models/gltf/Xbot.glb

SHA-256: `002f8d269de68e5dce3d25195caf390d1aa359bbfaae3fcf4c8dc78ec36c3ba5`

Source repository: https://github.com/mrdoob/three.js (MIT). The model is an example asset sourced from Mixamo; no independent commercial clearance is asserted here. This integration remains a research preview. Preserve source attribution when redistributing.

Rendering uses the approved direct native22 deformation in `experiments/native_pair_rig.py`: authored skin weights and inverse binds; no Core conversion, fitted elbows, model smoothing, or inferred contact physics. The asset is bundled so reviewed playback does not depend on a runtime download.
